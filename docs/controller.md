# Протокол контроллера

Это тот же договор, что в [hardware/INTERFACE.md](../hardware/INTERFACE.md). Прошивка ему следует. Хост в `src/sata_library` шлёт те же строки. Здесь нет `SEEK`, `MATE`, `HOME` и `POWER`: это команды каретки из первой примерки, текущая прошивка их не исполняет.

115200 8N1, одна команда в строке, одна строка ответа. Контроллер сам ничего не шлёт.

```
PING
ESTOP
STATE
SLOT <n> ON
SLOT <n> OFF
DISK <n> <d> ON
DISK <n> <d> OFF
```

`n` — слот 1…4. `d` — диск 1…4 на этой плате.

Успех: `OK` и хвост. Отказ: `ERR`, код, текст.

```
OK pong
OK estop
OK state slots=0,0,0,0 present=1,0,0,0 disks=0,0,0,0
OK slot 1 on
OK disk 1 2 on
```

В `STATE` четыре флага слотов, четыре флага PRESENT и четыре флага дисков активного слота. Если все слоты выключены, диски в ответе `0,0,0,0`.

- `SLOT n ON` выключает 12 В остальных слотов и их диски, потом включает слот `n`. Диски нового слота остаются выключенными.
- `DISK` при выключенном своём слоте — `ERR slot_off`.
- `ESTOP` гасит все слоты и все диски.
- Неизвестный слот или диск — `ERR bad_arg`.
- Платы нет на шлейфе — `ERR not_present`, 12 В не включается.
- В EEPROM нет `SLIB` — `ERR no_eeprom`, слот снова выключается.

Паузу 8 с между раскрутками держит хост. В прошивке этого таймера нет.

Живой порт открывается флагом `--port`. Без него команда останавливается с `not_connected` и на контроллер ничего не шлёт. `--dry-run` говорит с контроллером в памяти и печатает те же строки.
