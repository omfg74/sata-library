# Протокол контроллера

Строки UTF-8, одна команда на строку. Хост ждёт одну строку ответа. Контроллер не шлёт ничего сам.

Команды:

```
PING
ESTOP
HOME
SEEK <n>
MATE
RETRACT
POWER 0
POWER 1
STATE
```

Успех:

```
OK pong
OK estop
OK state bay=home z=retracted power=0
OK state bay=3 z=mated power=1
```

`bay` — `home` или номер отсека с 1. `z` — `retracted`, `between` или `mated`. `power` — `0` или `1`.

Отказ:

```
ERR z_not_clear разъём не отведён
ERR not_mated питание только после стыковки
```

Первое слово после `ERR` — код, дальше текст.

Положения отсеков в шагах хранит контроллер. Хост знает только номер. Пока разъём не в `retracted` или питание включено, `SEEK` и `HOME` должны отвечать ошибкой и не трогать мотор выбора. `POWER 1` — только из `mated`. `RETRACT` — только при `power=0`. `ESTOP` снимает питание и защёлкивает аварию, даже если концевик не доехал.

Эти запреты продублированы в `MockTransport`, чтобы хост можно было гонять без платы. `LineTransport` только переписывает строки и разбирает `STATE`; живого порта в этой итерации нет.
